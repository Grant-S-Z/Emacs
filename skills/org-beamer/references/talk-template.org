# WORK-FOCUSED CONFERENCE TALK (Chinese) --- full-featured frame template.
#
# How to use: copy this file, tick the frames this talk needs in the MENU
# below, delete the rest, then fill each kept frame. Lines starting with "# "
# are Org comments: they are guidance and do NOT export --- delete or keep, your
# choice. Run scripts/lint_org.py when done.
#
# Default shape: a formal talk, but the audience is here for the WORK, so keep
# background to the minimum needed to read the results and spend your slides on
# Approach + Results. Rough budget for a 12-18 min talk ~ 12-16 frames.
#
# FRAME MENU --- tick what you need:
#   [ ] 1. Motivation        1 frame    弱背景:为什么值得做 + 缺口
#   [ ] 2. Background        0-1 frame  只放读懂主体所必需的
#   [ ] 3. 工作主体 (Body)    主体       结构跟随来源 ------ 见下方说明,别套死模板
#   [ ] 4. Summary & outlook 1 frame    结论(写成 claim)+ 下一步
#   [ ] (backup)             Q&A        放在 \appendix 后,不计入页数
#
# HOW TO STRUCTURE THE BODY --- 不要硬套"方法 -> 结果"两节,让结构跟着来源走:
#   - 从论文转 beamer:跟论文的章节顺序走(通常就是各分析步骤 / 各结果).
#   - 日常工作汇报:按工作项或时间线走(这一阶段做了哪几件事).
#   下面三种 frame 形态只是样例(带图 / 两栏 / TikZ 示意图),复制并改名以匹配你的真实结构.
#
# THREE RULES that matter more than any lint fix (the linter can't check these):
#   - Conclusion-style titles. The title states the takeaway, not the topic.
#       bad:  ** 信号模型        good:  ** 太阳 HNL 产额由 X 主导
#   - One message per slide. Ask "what should they remember from this slide?"
#     If you can't answer in one sentence, split it.
#   - Figure-first. A large plot + one-line takeaway beats ten bullets and a
#     thumbnail. State units, and state the exposure / CL / dataset on the plot.
#     Caption with #+caption: (never a hand-typed centered line); add it when
#     there's room, drop it when tight --- but be consistent across the deck.
#     Side-by-side: figure LEFT, text RIGHT, and keep the text side uncrowded.
#
# ORG MATH SYNTAX:
#   - Inline math: \(...\)
#   - Unnumbered display math: \[...\]
#   - Never use $...$ or $$...$$ in Org prose.
# ============================================================================
